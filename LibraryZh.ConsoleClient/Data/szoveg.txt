HA A LINQ FELADAT EZT ÍRJA: „anonim típus publikus visszatérési típusként nem használható.”: A Models project alá csinálj egy LekérdezésEredmények „osztályt”, amibe olyan „record”-okat csinálj, amilyeneket a LINQ feladatok megkövetelnek. Pl.: public record LoanedBook(string Title, string BorrowerName);    Ezeket akkor kell használni, ha a LINQ lekérdezéseknél több Modellből (Books, Loans) is kell adatot kinyerni.

A LOGIC projectben eleje:
private readonly LibraryRepository repository;
public LibraryService(LibraryRepository repository) { this.repository = repository; }
Ezután a LINQ lekérdezések mind IEnumerable<VisszatérésiÉrték> típusú.

// 3) A három legtöbbször kölcsönzött könyv, cím és kölcsönzésszám visszaadásával
public IEnumerable<MostLoanedBooks> task3()
{
    return repository.ReadAllBooks()
        .OrderBy(x => x.Loans.Count)
        .Take(3)
        .Select(x => new MostLoanedBooks(x.Title, x.Loans.Count))
        .ToList();
}
